Project value

Make a difficult habit easier to observe honestly.

What the design needed to achieve

  • ✓

    Record a smoke before the moment passes.

  • ✓

    Show patterns without blame or medical claims.

  • ✓

    Keep every log on the user’s device.

Problem

Small moments disappear.

A tracker loses value when recording takes longer than the habit itself.

Risk

Judgment blocks honesty.

Harsh language can make people avoid the record they need to understand.

Direction

Keep the loop neutral.

Use one-tap input, clear trends, and calm language to support awareness.

Design decisions

Reduce effort while protecting honest reflection.

01

Log in one tap

Less input effort

The main action records a smoke at once. The same screen shows today’s count, the last time, and a clear undo.

Intended impact

More complete logs with quick recovery from accidental taps.

02

Report patterns, not scores

Neutral feedback

Daily and weekly views show counts, common times, change, and the longest gap without grading the user.

Intended impact

Help people notice patterns without adding shame.

03

Make location optional

Choice before context

Approximate location can add place patterns to future logs. It stays optional and never blocks logging.

Intended impact

Add useful context only when the user wants it.

04

Keep the record private

Data ownership

Seej uses no account, backend, ads, or analytics. Users can export CSV data or delete every log.

Intended impact

Make privacy visible through product behavior.

Product proof

The released screens keep logging and reflection separate.

Result

A focused private tracker reached the App Store.
