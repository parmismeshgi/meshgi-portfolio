## Turn a broad school website into a guided class decision.

### What the design needed to achieve

- ✓

Serve local learners in Farsi first, with complete English routes.

- ✓

Route children and adults through suitable placement questions.

- ✓

Keep test results provisional until staff review.

Problem

### Class choice starts vague.

Language, age, level, goal, and schedule all affect the right next step.

Risk

### A test can overpromise.

A written result cannot confirm speaking, listening, or the final class by itself.

Direction

### Guide, then confirm.

Use a short placement flow and make human review part of the answer.

Design decisions

## Match the flow to a real school conversation.

01

### Make Farsi the default

Local access

The main routes open in Farsi. English uses complete routes under the English section.

Intended impact

Meet the main local audience without removing bilingual access.

02

### Ask age before test questions

Correct route

The flow collects exact age before the test. Children aged three to five receive an oral-program result without a written test.

Intended impact

Avoid giving young learners questions that do not fit the school program.

03

### Branch after each answer

Shorter path

Each response can confirm, rescue, move to the next level, or reach a course result.

Intended impact

Ask only the next useful question.

04

### Keep staff in the result

Responsible placement

The closest course appears as a provisional result. Staff confirm speaking, listening, and the final class.

Intended impact

Use the test to guide a decision without presenting it as final.

Product proof

## The live experience connects the school story to one next action.

Home

### Find a class

The main page names the languages, audience, location, and direct class-finder action.

Placement

### Age-led route

The test uses age and current answers to choose the next question or course result.

Access

### Four tested widths

Public pages passed Farsi and English checks at 320, 390, 960, and 1280 pixels.

Result

## A bilingual school website now leads with class fit.

Live evidence

### Public bilingual product

The website serves Farsi and English information, class routes, and placement.

Verified boundary

### Provisional result

The test recommends the closest course while staff keep the final placement decision.

Measure next

### Placement value

Track flow completion, staff corrections, class inquiries, and route exits. Public results are not available.
