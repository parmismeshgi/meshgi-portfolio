Project value

Help people answer “What can I cook?” before they read the recipe.

What the design needed to achieve

  • ✓

    Show time, effort, cost, method, and servings early.

  • ✓

    Let practical filters narrow the recipe list.

  • ✓

    Help users recover when a search returns nothing.

Problem

Recipes answer too late.

A long story cannot help when the first question is time, effort, ingredient, or method.

Risk

More filters can add work.

A large filter system becomes another task when it does not match cooking decisions.

Direction

Decide before reading.

Put practical facts first and keep recovery close to every empty result.

Design decisions

Organize the product around the moment before cooking.

01

Put recipe facts first

Fast scanning

Recipe pages show time, effort, cost, method, and servings before ingredients and steps.

Intended impact

Help users reject or choose a recipe before deep reading.

02

Use filters as cooking questions

Practical choice

Course, intent, ingredients, timing, effort, method, and region help users express the meal they can make.

Intended impact

Turn browsing into a smaller, more useful set of choices.

03

Recover from no results

Useful empty state

The recipe list suggests the smallest useful change, such as removing one filter or the search term.

Intended impact

Keep the cooking task moving instead of ending at a blank page.

04

Design mobile-first for cooking

Kitchen use

The interface uses strong scanning, large tap targets, and reduced-motion support for phones and tablets.

Intended impact

Keep the recipe usable while hands and attention are busy.

Product proof

Clear food images support a structured cooking flow.

Result

A live Persian recipe finder supports the full choice-to-cooking path.

Live evidence

Public recipe product

Chaashni offers home discovery, recipe filters, suggestions, recipe details, and request recovery.

Verified boundary

Practical metadata

The product keeps cooking facts and useful recovery inside the main browsing flow.

Measure next

Cooking signals

Track recipe opens, filter use, empty-state recovery, saved URLs, and related-recipe visits. Public results are not available.
