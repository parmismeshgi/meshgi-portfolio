    Export

    Make a video file

    The film is drawn frame by frame from code, so it exports cleanly at 1920 × 1080.

    1. MP4, frame-exact (recommended). From the repository root, with Node 18+ and ffmpeg installed: 
      npm install --no-save playwright
npx playwright install chromium
node film/tools/export.mjs
      This writes film/export/parmis-orange.mp4 (1080p, 24 fps, music, story lines in the picture) and parmis-orange.srt. Add --clean for a version without the story lines, to put under your recorded voice, or --no-music for a silent picture track.
    2. Quick WebM from the browser. Serve the folder with npx serve film, open the local address, and press Record .webm. It records in real time for 90 seconds, then downloads the file.
    3. Add your voice. Import the MP4 into any editor (CapCut, iMovie, Premiere, DaVinci Resolve). Import the .srt as a guide track, record each line at its timestamp, and keep the music under the voice. The music already dips during every line.
